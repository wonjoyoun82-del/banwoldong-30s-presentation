# 반월동 802-1 정원형 베이커리 카페 30초 시네마틱 프레젠테이션

전주시 덕진구 반월동 802-1번지 신축 베이커리 카페 계획안의 3D 모델, 2D CAD 도면, VWorld 항공지적도, 그리고 Google Veo 3.1 기반 30초 마스터 시네마틱 프레젠테이션 비디오를 인터랙티브하게 탐색할 수 있는 웹 대시보드입니다.

## 주요 기능
- **30초 마스터 프레젠테이션 비디오**: Google Veo 3.1 4-Shot(가로접근, 중정, 2층보이드, 1층평면) 무손실 합성 영상 (720p HD 60fps)
- **Three.js 실시간 3D 뷰어**: 1,062개 건축 솔리드 실시간 렌더링, 3D 지출입구 핀 마커 및 동선 표시
- **공식 CAD 도면 & GIS 항공영상 갤러리**: VWorld 지적 정사사진, A-101 배치도, A-201/202 평면도, A-401/403 입면도 고화질 열람
- **가로 경관 비포 & 애프터 슬라이더**: 도로 현황과 신축 완공 3D 가로 파사드 비교

## 제작 도구
- 3D 모델링 및 CAD 정합: Codex r6
- 시네마틱 AI 영상 생성: Google Flow (Veo 3.1 - Lite)
- 워크플로우 & 스킬 자동화: Antigravity CLI (`cad3d-to-cinematic`)
